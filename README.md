# 21st_century_music_theory_anki
# Music Theory Anki Deck

An Anki flashcard deck for learning and reviewing music theory through spaced repetition.

This project draws on *Music Theory for the 21st-Century Classroom* by Robert Hutchinson, alongside other textbooks, educational websites, reference materials, and music theory resources. The goal is to consolidate information from multiple sources into a convenient, accessible study resource.

## Contents

The deck covers music theory concepts drawn from multiple educational resources. Topics and coverage may evolve as new cards are added.

## Getting Started

1. Download the `.apkg` deck file from the repository or its [Releases](../../releases) page.
2. Open Anki on your computer or mobile device.
3. Import the downloaded file into Anki.
4. Start reviewing!
